# Editorial Standards

**MT Media AI — Truth and Accuracy Protocol**

---

## Our Standard

Every claim is sourced. Every stat is dated. Every external reference is linked. No exceptions.

---

## How We Handle Evidence

| Principle | Practice |
|-----------|----------|
| **Primary sources preferred** | Original research, official documentation, direct quotes, first-party data |
| **Secondary sources cited with context** | "Per [Source], [claim]" — never presented as original finding |
| **Estimates clearly marked** | "Estimated," "approximately," "per internal benchmark" — never stated as fact |
| **Uncertainty acknowledged** | "Preliminary data suggests," "early indicators show" — confidence intervals where applicable |
| **No cherry-picking** | Contradictory evidence noted. If the data doesn't support the claim, the claim is revised. |

---

## How We Handle Corrections

| Principle | Practice |
|-----------|----------|
| **Errors corrected publicly** | Visible correction notice on the affected page |
| **Timestamped** | Date and time of correction included |
| **Explanation provided** | What changed, why, and what the correct information is |
| **No silent edits** | No content changes without a correction log entry |
| **Version history** | Git commit history serves as immutable audit trail |

---

## What We Refuse to Claim

| Refusal | Rationale |
|---------|-----------|
| **No guarantees** | Outcomes depend on client reputation, competitive landscape, and AI system evolution |
| **No endorsements** | We do not endorse platforms, tools, or third parties. We evaluate. |
| **No universal applicability** | "Works for every business" — never. Context is everything. |
| **No "proven" without citation** | "Proven" requires a specific, linked study or dataset. Internal benchmarks labeled as such. |
| **No outcome promises** | We build infrastructure. The market decides the result. |

---

## The Nina Filter

Every public output passes through internal adversarial review before it ships.

**The Nina Filter is MTM's quality gate:**
- **Skeptic by design** — assumes the claim is wrong until evidence forces acceptance
- **Checks:** sourcing, logic, framing, overclaim, boundary violation, client sensitivity
- **Output:** Pass / Revise / Kill
- **The name is public. The process is ours.**
