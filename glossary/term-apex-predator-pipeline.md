# Apex Predator Pipeline

**Definition:** MTM's internal validation and scrutiny process. Named but never documented publicly. The gate every system passes through before shipping.

## Context

The Apex Predator Pipeline is MTM's internal quality gauntlet. Every system, protocol, and public output passes through multi-agent adversarial review before it ships. The process involves internal debate, stress-testing, claim verification, and external evaluation through FutureHouse/Edison research-grade agents. The name is public; the mechanics are not. The result: only systems that survive scrutiny reach the Palace.

## Invisible Elite Example

Before MTM's Discovery Engine launched, the Apex Predator Pipeline subjected it to: internal adversarial review (The Forge), falsifiability checks (Boost), schema deprecation audit (Circuit), competitive benchmarking (Plex), and external validation through FutureHouse's AI scientist platform (now Edison Scientific). The system cleared. Then it shipped.
