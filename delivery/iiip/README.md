## 2. Technical Architecture & Zero-COGS Principles
The IIIP delivery engine is architected under the **Zero-COGS Mandate** and **Library Supremacy**:
- **Zero Runtime Dependencies**: Written in high-performance vanilla HTML5, CSS3, and modern JavaScript (`iiip-engine.js`). Requires zero Node.js daemon or external server-side computation during client viewing.
- **Client-Side Hydration**: Dynamic prospect injection via JSON payload (`window.IIIP_CONFIG` or `iiip-config.sample.json`), enabling rapid turn-key personalization without rebuilding layout scaffolding.
- **Local Sovereignty**: Client interactions (audio scrubbing, 3D tilt physics, interactive tabs, dynamic lightboxes) execute in-browser with zero third-party telemetry, trackers, or cookie banners.
- **Defensive Edge Hardening**: Fully isolated from external file manipulation; client-facing controls are strictly sandboxed.
